## プロンプト本文（ここから下をコピー）

中古車の買取・販売店「AUTOBEST」のLINE公式アカウント用UIを作ってください。
スマートフォン縦画面（390 × 844px）のアートボードを8枚、1つのキャンバスに並べます。

### この店について

福岡本社と神奈川支店の2拠点。乗用車・軽、トラック・バス、重機・作業車、
その他車両の4カテゴリを扱う。買取査定と販売の両方をLINEから受け付ける。
お客様は年配の方や現場の職人さんも多く、字が小さいと読まれない。

### デザインの方向

**ポップで明るく、親しみやすく。** 中古車店のLINEなので、堅い企業サイトではなく
「近所の頼れる店」の空気にする。アイコンは線画だけで済ませず、
車やトラックは色面で描いたイラスト調にして、見た瞬間に何のボタンか分かるようにする。

やってはいけないこと:

- **暗い配色にしない。** 全体を白・アイボリー基調にして、色は面で効かせる
- **紫を使わない。** サポート系の色は紫ではなくティール（青緑）
- **のっぺりしたフラットにしない。** ボタンには下辺の影（`box-shadow: 0 3px 0 <暗い同系色>`）を
  付けて、押せることが分かる立体感を出す
- **モノクロの線アイコンだけで組まない。** 情報量が同じでも冷たく見える

### 配色（確定。この値をそのまま使う）

タブごとのテーマ色:

|---|---|---|---|---|
| 車を探す | `#4FA3F0` | `#1E7FD6` | `#1268C4` | `#1268C4` |
| 車を売る | `#FF8A2B` | `#EE6A12` | `#E2600A` | `#C85A0E` |

共通:

```
ヘッダー（LINEのトーク上部）  #1F3358
濃い文字・見出し              #16283F / #22262D
```

タブの色は**背景・上辺・アイコンだけ**に使う。6つのボタン面は白で統一する。
3タブとも色で塗り分けると画面がうるさくなり、どれが押せるのか分かりにくくなるため。

### 守る制約

- **入力欄の文字は16px以上。** iOS Safariは15px以下の入力にフォーカスすると
  勝手に拡大し、そのあと縮まらない
- **タップ領域は44px以上**
- **リッチメニューは 2500 × 1686px** を想定した比率（上部にタブ3つ、下に3列×2行の6ボタン）
- 長い車名（「トヨタ ハイエースバン スーパーGL ダークプライムII」）、
  **価格応談**、重機の**稼働時間（1,240h）** でも崩れないこと
- 日本語フォントは Noto Sans JP（400/500/700/900）

### 作る8画面

**上段：LINEトーク画面（リッチメニュー3タブ＋通知）**

1. **トーク＋案内カード＋タブA「車を探す」**
   友だち追加直後のあいさつ、「ご用件をお選びください」の案内カード（車のイラスト入り）、
   下にリッチメニュー。ボタンは
   販売在庫を探す／条件から検索／新着入庫／お気に入り／来店・商談予約／福岡・神奈川の店舗。
   各ボタンは日本語ラベルの下に小さな英字（STOCK LIST, SEARCH, NEW ARRIVALS…）を添える。

2. **タブB「車を売る」**
   無料買取査定／高額査定実績／高額査定の理由／買取までの流れ／必要書類／査定について相談。

3. **タブC「サポート」**
   よくある質問／問い合わせ／予約確認／通知設定／会社・店舗案内／Webサイト。
   トーク側にはFAQのリスト（「ローンが残っていても売れますか」など）を出す。

4. **新着車両のFlex Message通知**
   カルーセルで2台。写真・新着バッジ・車名・年式/走行距離・支払総額・拠点・「詳細を見る」。
   下に「通知条件：ハイエース／〜350万円／福岡本社［変更］」。

**下段：LINE内ブラウザ（LIFF）の4画面**

5. **在庫検索**
   絞り込みチップ（乗用車・軽／トラック・バス／重機・作業車／その他／福岡本社／〜350万円／新着順）、
   「該当 N台」、車両カード4枚。**価格応談**と**稼働時間表記**の車両を必ず1台ずつ混ぜる。

6. **車両詳細＋問い合わせ**
   写真スライダー（1/4）、新着バッジ、在庫番号、拠点、車名、支払総額と車両本体価格、
   スペック表（年式・走行距離・車検・ミッション・ボディカラー）、車両の状態、
   下部固定に［お気に入り］［来店・商談予約］［この車について問い合わせる］。

7. **無料買取査定の入力**
   4ステップ（車両情報／写真／連絡先／確認）の1枚目。
   カテゴリ選択、メーカー、年式、車名、走行距離（重機は稼働時間）、
   写真の枠（車検証・外装・内装）、プライバシーポリシー同意。

8. **来店・商談予約**
   対象車両のカード、拠点の選択（住所つき）、第1〜第3希望の日時、
   「この時点では仮予約です」の注記、［仮予約を申し込む］。

### 注記として画面の外に置くもの

- 4番の通知は**プッシュ配信**で、無料プラン（月200通）では通数を消費する。
  条件一致が50人なら1台の公開で50通。運用前に要相談。
- 住所・営業時間・電話番号は未確定のため `[福岡本社 住所]` のように角括弧で残す。
  車両はすべてサンプル、写真はプレースホルダー。

## 補足：なぜこの配色になったか

最初の案は**参考にした他社LINE（モバステ）とかけ離れて地味**だったため作り直し、
2案目は**暗く、サポート色が紫**で「くらい」と却下された。
3案目で全体を明るくし、紫をティールに置き換えて承認された。

つまり上の「やってはいけないこと」は、実際に一度ずつ却下された内容。
**ここを外すと同じやり直しになる。**

## 補足：実装との対応

このデザインは既に実装に反映済み。同じ色が次の場所に入っている。

| デザイン | 実装 |
|---|---|
| Flexカルーセル（4・5画面） | `src/FlexBuilder.php` の `NAVY` `BLUE` `BLUE_LT` `PRICE` `AMBER` |
| リッチメニュー3タブ | `src/RichMenuDefinition.php`（2500×1686、タブ高346、3列×2行） |
| 車両詳細（5画面） | `public/car.php` の `:root` |
| 査定・予約フォーム（7・8画面） | `public/_form_layout.php` の `:root` |

新しい画面を足すときは、これらのCSS変数を読んで同じ値を使うこと。
